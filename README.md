# パネル開け支援ツール (PanelOpenTool)

画像を好きな形に分割してパネルを作成し、1枚ずつ開閉できるブラウザツールです。
「パネル開けチャレンジ」のような企画で、画像をどのパネルから開けるか楽しむ用途を想定しています。

## デモ

`index.html` をブラウザで開くだけで利用できます（ビルド不要）。

## 主な機能

- **作成モード**
  - 画像を読み込み、ドラッグした線でパネル（多角形）を分割
  - パネルの色テーマを変更
  - 分割操作を1つ前に戻す（Undo）／全消去
  - テキストボックスの追加・編集・削除（フォントサイズはピンチではなく画面幅フィット＋スクロールで編集しやすく調整）
- **オープンモード**
  - パネルをタップして開閉（開いたパネルに紐づくテキストも表示/非表示が連動）
  - 完成画像を保存（対応端末では共有シートからそのまま投稿可能）
  - X（旧Twitter）へのポスト用定型文を設定して投稿画面を開く
- 作業内容は `localStorage` に自動保存され、リロード後も復元されます

## 使い方

1. 「画像読込」から画像を選択
2. 作成モードで線を引いてパネルを分割し、必要に応じて文字を追加
3. 「オープンモード」タブに切り替え、パネルをタップして開閉を確認
4. 「画像保存」で結果を保存、または「𝕏でポスト」から投稿

## 技術構成

- Vanilla JavaScript + [Fabric.js](http://fabricjs.com/)（`index.html` からCDN読み込み）
- 素のHTML/CSS/JSのみで構成され、ビルドツールやサーバーを必要としません
